# Link-Do 产品需求文档 (PRD)

> **版本**: v1.0
> **更新日期**: 2026-04-03
> **产品名称**: Link-Do（参考产品: Blitzit）
> **平台**: macOS 桌面端（Tauri 2 + React）
> **后端**: Go API + Notion OAuth

---

## 1. 产品定位

Link-Do 是一款**桌面端任务管理与专注计时工具**，通过 Notion 同步实现数据持久化，支持 AI 自然语言批量建项。核心差异化在于**三种窗口形态的无缝切换**——从全功能列表视图，到窄屏计时视图，再到沉浸式胶囊悬浮窗，帮助用户在「规划」与「执行」之间丝滑过渡。

### 一句话

> 桌面端待办 + Notion 同步 + 悬浮计时胶囊，让你专注当下任务。

---

## 2. 目标用户

| 用户画像              | 描述                                           |
| --------------------- | ---------------------------------------------- |
| 独立开发者/自由职业者 | 使用 Notion 管理项目，需要桌面端快速操作和计时 |
| 知识工作者            | 日常任务多、切换频繁，需要聚焦当前任务的工具   |
| 效率爱好者            | 追求沉浸式工作流，希望最小化干扰               |

---

## 3. 核心用户旅程

```
打开应用 → 查看 Collection 列表 → 进入某个 Collection →
选择任务开始计时 → 窗口缩窄为计时模式 →
进入 Focus Mode（胶囊悬浮窗） → 完成任务 → 回到列表
```

**窗口尺寸**: 标准桌面窗口（可调节）

**窗口尺寸**: 宽度 343px，高度自适应

**触发条件**: 点击 "Blitzit now" 或点击某个任务开始计时

- **Collection 图标 + 下拉切换**

#### 4.3.3 快速操作

### 4.4 Focus Mode — 胶囊悬浮窗（图4）

**窗口尺寸**: 约 343px × 48px（胶囊形状）
**窗口行为**: **Always on Top**（常驻最前），可拖拽定位

#### 4.4.1 显示内容

- **任务名称**: 左侧，白色文字
- **实时计时器**: 右侧，`HH:MM:SS` 格式

#### 4.4.2 交互

- **单击**: 展开回计时模式（343px 窄屏）
- **拖拽**: 自由移动胶囊位置
- **可能的扩展**: 悬停显示快捷操作（暂停/完成/下一个任务）

## 7. Notion 同步规格

### 7.1 认证

- 使用 **Notion OAuth 2.0** 授权
- 用户授权后获取 access_token，服务端存储

### 7.2 同步策略

| 方向             | 触发时机            | 行为                           |
| ---------------- | ------------------- | ------------------------------ |
| Link-Do → Notion | 创建任务            | 在 Notion 数据库创建对应页面   |
| Link-Do → Notion | 完成任务            | 更新 Notion 页面状态字段为完成 |
| Link-Do → Notion | 更新时间            | 更新 Notion 页面的时间记录属性 |
| Notion → Link-Do | 应用启动 / 手动刷新 | 拉取 Notion 数据库最新数据     |

### 7.3 冲突处理

- 以最后写入为准（Last Write Wins）
- 同步失败时**可感知、可重试**，UI 显示同步状态

---

## 8. AI 批量建项（后续迭代）

- **输入**: 自然语言描述（中/英文），如 "这周要完成登录页、注册页、忘记密码三个页面"
- **处理**: 服务端 Go API → LLM 解析 → 结构化 JSON
- **输出**: 可预览的任务列表，用户确认后批量创建
- **限制**: 单次最多 20 条，超限报错；非法输入有明确错误提示

## 11. 窗口管理技术要点

| 状态       | 宽度    | 高度   | Always on Top | 可调节     |
| ---------- | ------- | ------ | ------------- | ---------- |
| 标准视图   | ~1440px | ~900px | 否            | 是         |
| 计时模式   | 343px   | 自适应 | 可选          | 高度自适应 |
| 胶囊 Focus | ~343px  | ~48px  | **是**        | 否（固定） |

- 窗口状态切换通过 **Tauri Window API** 实现（`setSize`, `setAlwaysOnTop`, `setDecorations`）
- 胶囊模式去除标题栏装饰（`decorations: false`）
- 胶囊支持拖拽（通过 Tauri `startDragging` API）

## 12. 非功能性需求

| 维度         | 要求                                               |
| ------------ | -------------------------------------------------- |
| **性能**     | 计时器 UI 刷新 ≤ 16ms（60fps），窗口切换 < 300ms   |
| **离线**     | 无网络时可正常使用本地任务与计时，联网后自动同步   |
| **数据安全** | OAuth token 安全存储（Keychain），不在本地明文保存 |
| **系统资源** | 胶囊模式 CPU 占用 < 1%，内存 < 50MB                |
| **跨版本**   | macOS 12+ 支持                                     |
